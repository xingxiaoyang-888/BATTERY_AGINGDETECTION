# 面向 Journal of Power Sources / Applied Energy 的论文实施路线

## 0. 文档用途

本文档用于把当前“公司工程平台”升级为可投稿高水平期刊的研究项目，并作为后续任务的执行输入。目标不是把现有结果写得像论文，而是围绕一个明确科学问题补齐数据、方法、对照实验、外部验证和可复现证据。

目标期刊：

- **首选：Journal of Power Sources（JPS）**——适合突出钠离子电池的寿命机理约束、混合建模、早期预测、不确定性和跨工况泛化。
- **条件路线：Applied Energy**——只有在加入运行优化、储能调度、冷却能耗和退化成本闭环后才成立；仅做SOH/RUL算法通常不够。

建议采用“两篇递进式论文”，而不是用一个稿件同时承载所有目标：

1. Paper A / JPS：不确定性感知、删失感知、可迁移的钠电混合寿命数字孪生。
2. Paper B / Applied Energy：基于该数字孪生的退化感知热管理与储能运行优化。

## 1. 当前研究起点

### 1.1 已有资产

- Modelica/FMI 2.0钠离子电池包模型，包含电、热、冷却、空间温度和SOH输出。
- 10种可运行FMU规格以及Streamlit + FastAPI数字孪生平台。
- 恒流/时变工况、冷却边界、故障注入和三维热场诊断。
- RWTH商业钠离子老化DOD100子集：47只电芯、54,552行循环特征、15类工况。
- 显式右删失的90%/85%/80% EOL标签。
- 队列速率、个体历史、应力修正和XGBoost短期残差校准的寿命引擎。
- 严格按电芯留一（LOCO）回测、OOD、置信区间和API工程门禁。

### 1.2 当前可引用的内部验证结果

| 项目 | 当前结果 |
|---|---:|
| 单步SOH XGBoost RMSE | 0.000215 |
| 相对持久性基线改善 | 26.4% |
| 严格47折LOCO RUL MAE | 417.2 cycles |
| 严格LOCO区间覆盖率 | 80.0% |
| 75%后期观测LOCO MAE | 81.8 cycles |
| 75%后期区间覆盖率 | 94.4% |
| AI门禁后验证集MAE改善 | 3.0% |

这些结果能证明“系统可工作、验证协议已建立”，不能证明“已经具备显著论文创新”。特别是80% EOL仅7/47个真实事件，25%早期观测点MAE约753圈，50Ah公司电芯仍是OOD。

## 2. 推荐的主论文定位（JPS）

### 2.1 暂定题目

英文方向：

> **An uncertainty- and censoring-aware hybrid digital twin for early-life prognosis of commercial sodium-ion batteries under domain shift**

中文表述：

> 面向域偏移的商业钠离子电池早期寿命预测：一种融合物理、电热应力、右删失队列与不确定性的混合数字孪生方法

### 2.2 核心科学问题

公开钠电数据规模有限、达到80% EOL的事件稀少、不同容量和工况之间存在显著域偏移。如何在不伪造删失寿命标签、不泄漏同一电芯循环信息的条件下，把物理仿真、早期历史和数据驱动模型融合起来，并给出可校准的不确定性和“何时不应相信模型”的域外判断？

### 2.3 论文主张

主张必须被实验逐条支撑：

1. **混合状态表示**：使用FMU/物理层形成电热应力和状态先验，数据模型只学习剩余偏差或退化速率，而不是从零拟合全部寿命关系。
2. **删失感知预后**：未达到EOL的样本仅提供寿命下界或生存信息，不生成虚假的RUL真值。
3. **域偏移门禁**：容量、SOC窗口、温度、倍率和SOH状态共同构成训练域，模型对50Ah等域外对象主动降低置信度。
4. **多源校准**：公开队列先验、资产个体历史和短期残差模型按证据强度动态融合。
5. **概率化输出**：输出经校准的RUL区间、覆盖率和区间宽度，而不是只比较单点MAE。

如果最终实验不能证明第1项相对强基线有稳定增益，应把论文收缩为“删失 + 不确定性 + 域适应”，不要强行宣称physics-informed。

## 3. JPS方法路线

### WP1：数据治理与预注册协议

必须先冻结：

- 电芯身份、化学体系、额定容量、温度、充放电倍率、SOC窗口和静置规则；
- 循环定义、容量参考值、SOH计算和异常循环剔除规则；
- 训练/验证/测试按电芯或实验实体分组，禁止随机拆循环；
- 90%、85%、80%三种EOL阈值和右删失规则；
- 观测比例10%、25%、50%、75%和固定预测跨度32/64/128循环；
- 公司数据在任何模型选择前锁定为外部测试集。

交付物：数据字典、质量报告、数据血缘、哈希清单、预注册评估协议。

### WP2：统一的多保真状态空间

构建三类特征：

- **观测状态**：SOH、容量、内阻、库仑效率、累计Ah吞吐量。
- **工况状态**：温度、温差、充放电倍率、SOC上下限、静置时间。
- **物理状态**：FMU估计的平均/最高温度、温差、热积累、冷却负荷、等效内阻和应力指标。

物理层应通过参数辨识而不是人工任意调参。至少对OCV、内阻、热容、换热和退化系数做敏感性/可辨识性分析，明确哪些参数可由现有实验识别。

### WP3：删失感知混合预后模型

建议实现并比较两条候选方法：

**方案A：分层速率 + 残差学习**

- 分层/贝叶斯或加权队列模型估计基础退化速率；
- FMU电热应力提供物理倍率；
- XGBoost/时序模型学习短期残差；
- conformal或加权分位数构造RUL区间。

优点：与当前代码衔接最直接，可解释性强，容易做消融。

**方案B：生存分析 + 单调轨迹模型**

- 使用AFT/Cox/随机生存森林或离散时间生存模型处理右删失；
- 使用单调约束网络/状态空间模型预测SOH轨迹；
- 将EOL生存分布与轨迹交叉校准。

优点：统计处理更规范；缺点是实现与调参成本更高。

建议先完成A并形成强基线，再根据事件数决定是否引入B。只有7个80%事件时，不宜用高容量深度生存网络作为主模型。

### WP4：公司50Ah小样本域适应

公司数据不是简单“微调一下”，而是用于回答跨容量与跨协议泛化问题。

建议分三层：

1. **零样本**：直接使用公开模型，必须显示OOD和宽区间。
2. **少样本校准**：用每只电芯早期10%–25%数据校准速率、物理参数和不确定性。
3. **外部验证**：公司电芯不参与主模型结构与超参数选择，只用于最终锁箱评估。

可比较：无校准、线性速率校准、CORAL/importance weighting、分层贝叶斯随机效应、参数高效残差校准。

## 4. 数据与实验矩阵

### 4.1 公开数据

- RWTH 47只已处理电芯作为主要公开队列。
- Wenzhou和Mendeley NFM仅在完成化学体系、单位、循环协议和电芯独立性审计后加入。
- 不把同一电芯的不同温度文件或重复导出文件当作独立电芯。

### 4.2 公司50Ah数据：最低配置与强配置

**最低可投稿配置**（仍有审稿风险）：

- 12只电芯；
- 3个温度 × 2个倍率/工况 × 每组2只重复；
- 至少覆盖到85% SOH；其中尽量有一部分达到80% EOL；
- 固定周期进行容量标定、HPPC/内阻或可替代的脉冲测试。

**更有竞争力的配置**：

- 18–24只电芯；
- 3个温度 × 2个倍率/动态工况 × 每组3–4只重复；
- 至少6–10只达到80% SOH；
- 包含恒流与代表性动态负载，保留完整电压、电流、温度和时间序列。

建议工况框架（必须服从厂商安全边界）：

| 因素 | 建议水平 |
|---|---|
| 温度 | 10°C / 25°C / 40–45°C |
| 充放电倍率 | 0.5C / 1C，必要时加入安全允许的加速工况 |
| SOC窗口 | DOD100主线 + 10%–90%或20%–80%外部工况 |
| 重复数 | 最低2，推荐3–4 |
| 参考测试 | 定期容量、内阻/脉冲、静置OCV、温度一致性 |

如果项目周期不足以等待80% EOL，应把主终点调整为85% EOL或固定跨度SOH预测，并在摘要中明确，不能以外推结果代替真实事件。

## 5. 对照、消融和评价协议

### 5.1 必须包含的基线

- 持久性/线性外推；
- 指数或半经验退化模型；
- XGBoost/LightGBM类树模型；
- LSTM/Transformer时序基线（数据量允许时）；
- 队列或生存分析基线；
- 纯FMU/物理模型；
- 提出的混合模型。

### 5.2 核心消融

- 去掉物理/FMU特征；
- 去掉右删失处理；
- 去掉个体历史；
- 去掉AI残差层；
- 去掉OOD门禁；
- 去掉不确定性校准；
- 固定融合权重 vs 证据自适应权重。

### 5.3 指标

**SOH轨迹**：MAE、RMSE、最大绝对误差、单调违例率。

**RUL事件样本**：MAE、RMSE、相对误差；MAPE仅在真实RUL远离0时使用。

**删失样本**：寿命下界一致性、C-index、time-dependent Brier score或适合所选生存模型的指标。

**概率预测**：PICP/覆盖率、MPIW/区间宽度、coverage-width criterion、可靠性图。

**域外检测**：OOD AUROC/AUPRC、域内/域外误差分层、置信度—误差相关性。

**工程性能**：API延迟、并发、失败降级、FMU求解耗时和内存。

### 5.4 统计要求

- 嵌套Group/LOCO验证；模型选择不能看锁箱测试集。
- 报告每折结果、均值、标准差和95% bootstrap置信区间。
- 比较模型用配对bootstrap、Wilcoxon或适合误差分布的检验，并报告效应量。
- 对多组模型/工况比较进行多重检验控制。
- 同时报告失败案例和最差工况，不只展示平均值。

## 6. JPS投稿门槛（Go / No-Go）

以下是项目内部门槛，不是期刊官方门槛：

### Gate A：数据可信

- 无电芯级泄漏；
- 所有数据有唯一身份和工况元数据；
- 右删失处理通过自动测试；
- 公司锁箱集在模型冻结前不可见。

### Gate B：方法有效

- 在严格Group/LOCO下，主模型相对最强非混合基线有稳定改善，而不是只在随机拆分下改善；
- 改善在多数折和关键工况成立；
- 消融能够解释改善来自何处。

建议目标：主指标相对最强基线改善达到约10%以上，或在误差相近时显著提高区间校准/域外安全性。若达不到，不应在标题中强调“superior accuracy”。

### Gate C：不确定性可信

- 名义90%区间的外部覆盖率目标为85%–95%；
- 区间宽度随观测信息增加而合理收缩；
- OOD输入的区间应扩大、置信度应下降。

### Gate D：外部验证

- 至少完成一个未参与训练的数据源或公司50Ah锁箱测试；
- 清晰报告零样本与少样本校准前后差异；
- 不把50Ah OOD结果表述为“同规格精确预测”。

### Gate E：可复现

- 数据处理、训练、评估和绘图均脚本化；
- 固定随机种子、环境、版本和数据哈希；
- 一条命令生成论文主表和主图。

任一A/D门槛未通过，优先补实验，不进入JPS正式投稿。

## 7. Applied Energy递进路线

### 7.1 适合Applied Energy的问题

Applied Energy需要从“电池预测准确”上升到“预测如何改善能源系统运行”。建议问题：

> 如何利用不确定性感知的钠离子电池数字孪生，在满足热安全和功率需求的同时，联合优化冷却能耗、退化成本、可用能量和寿命风险？

### 7.2 需要新增的决策层

- 数字孪生驱动的MPC/鲁棒MPC或场景优化；
- 决策变量：充放电功率、SOC窗口、冷却流量/温度、备用裕量；
- 约束：温度上限、温差、SOC、SOP、RUL风险和OOD置信度；
- 目标：电费/收益、冷却能耗、退化成本、可用容量、失效风险。

### 7.3 系统级对照

- 规则控制；
- 只考虑电价/效率的MPC；
- 使用确定性寿命点预测的退化感知MPC；
- 使用RUL区间与风险约束的鲁棒数字孪生MPC。

### 7.4 Applied Energy必须增加的指标

- 系统往返效率和冷却辅助能耗；
- 收益/运行成本、退化成本和可用能量；
- 温度/温差超限次数；
- 等效寿命消耗和维护风险；
- 在预测偏差与OOD场景下的鲁棒性；
- 不同气候、电价、光伏/负荷曲线下的年度或长周期仿真。

只有当数字孪生带来可重复、统计显著且具有工程量级的系统收益时，才以Applied Energy为目标。否则主投JPS更匹配。

## 10. 风险与备选策略

| 风险 | 表现 | 对策 |
|---|---|---|
| 80%事件过少 | RUL误差和区间不稳定 | 主分析增加85%终点，80%作为有限证据结果 |
| 50Ah域差过大 | 零样本误差高 | 分层校准、物理参数辨识、小样本域适应 |
| AI增益有限 | 当前仅1.7%–3% | 不强调深度学习，转向删失、校准与安全门禁贡献 |
| FMU参数不可辨识 | 物理层无法可信校准 | 做灵敏度分析，删除不可辨识自由度 |
| 公司数据周期长 | 迟迟没有EOL | 并行公开数据论文工作，采用85%终点但诚实说明 |
| 论文过于工程化 | 缺少科学问题 | 所有平台功能都必须服务于明确假设和对照实验 |
| Applied Energy范围不匹配 | 只有预测无系统收益 | 先投JPS；完成MPC和经济评价后再投AE |

```text
F. JPS论文详细目录、每张主图和每个主表要证明的结论。

先审计和设计，不要立即大规模训练。若发现当前证据不支持某项主张，应修改主张而不是包装结果。
```

## 12. 最终原则

“高大上”应体现在问题定义、证据链和工程闭环，而不是术语堆叠。真正能提高JPS/Applied Energy命中率的是：无泄漏数据、合理删失处理、可校准区间、外部50Ah验证、强基线、完整消融、统计显著性和可复现代码。
